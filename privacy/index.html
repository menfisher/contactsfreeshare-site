Privacy Policy

Effective date: May 16, 2026

ContactsFreeShare is a local desktop web app for maintaining a shared contact directory, syncing selected contact data with Google Contacts, saving shared app data to Google Drive, and creating printable address book PDFs.

Information ContactsFreeShare Uses

Depending on which features are enabled, ContactsFreeShare may use:

  • Google profile and email information to identify the connected Google account.
  • Google Contacts data to import contacts into ContactsFreeShare and upload user-approved contact edits back to Google Contacts.
  • Google Drive access to create, read, update, move, and delete files and folders used by ContactsFreeShare for shared app data, app settings, meeting data, field list layouts, address book PDFs, backup files, editor lock data, and app revision data.
  • Local app data stored on the user's computer, including contacts, meetings, field lists, PDF output, settings, logs, and uploaded contact photos.

How Google Data Is Used

ContactsFreeShare uses Google data only to provide user-facing app features selected by the user or app administrator. Google Contacts data is used for contact import and contact update workflows. Google Drive file access is used to create, read, update, and delete ContactsFreeShare files and folders needed for shared app data, backups, PDF output, and editor coordination.

Google Drive Access Scope

ContactsFreeShare requests Google Drive access that can manage files in the connected Google Drive account. This access is used so the app can create and maintain its ContactsFreeShare folder structure, sync shared app files, save generated PDFs and backups, manage editor lock files, and clean up ContactsFreeShare PDF files when Google Drive moves them outside the app folder after another shared user removes them.

ContactsFreeShare does not use Drive access to review, collect, or share unrelated Google Drive content. The app limits its Drive operations to ContactsFreeShare folders and files, app-created files, and folders or file IDs that the user provides in app settings.

Google API Limited Use Disclosure

ContactsFreeShare's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

ContactsFreeShare does not sell Google user data, use Google user data for advertising, transfer Google user data to unrelated third parties, or use Google user data to train generalized artificial intelligence or machine learning models.

Where Data Is Stored

ContactsFreeShare stores app data locally on the user's computer. When Google sync is enabled, ContactsFreeShare also stores selected shared app data in the connected user's Google Drive. ContactsFreeShare does not operate a separate public cloud database for user contact data.

Data Sharing

ContactsFreeShare does not sell or rent user data. Shared app data may be visible to other users or editors who have access to the same Google Drive files or folders used by the ContactsFreeShare installation.

User Control And Deletion

Users can control or remove app access in these ways:

  • Disconnect Google from the ContactsFreeShare Google Connect page.
  • Remove ContactsFreeShare access from the user's Google Account security settings.
  • Delete ContactsFreeShare local app data from the user's computer.
  • Delete ContactsFreeShare-created files and folders from the user's Google Drive.

Security

ContactsFreeShare uses Google OAuth to request access to Google data. Users should only install ContactsFreeShare from a trusted source and should keep their computer, browser, and Google account protected.

Changes To This Policy

This policy may be updated as ContactsFreeShare changes. The effective date above will be updated when material changes are made.
